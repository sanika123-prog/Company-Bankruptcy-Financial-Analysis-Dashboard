# Company Bankruptcy & Financial Analysis Dashboard

## Project Overview

This project focuses on analyzing company financial data and exploring patterns related to corporate bankruptcy using an interactive Power BI dashboard. The dashboard helps users understand financial indicators and identify trends associated with company financial health.

## Objectives

* Analyze company financial performance.
* Explore financial indicators associated with bankruptcy.
* Identify patterns and trends in company financial data.
* Present insights through interactive visualizations.

## Tools & Technologies

* Microsoft Power BI Desktop
* Data Visualization
* Financial Data Analysis

## Project File

* `Company Bankruptcy & Financial Analysis Dashboard.pbix`

## Features

* Interactive Power BI dashboard.
* Visual analysis of financial indicators.
* Exploration of bankruptcy-related patterns.
* Financial data visualization and reporting.
* Filters and slicers, where available, for interactive analysis.

## How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Update data source paths or credentials if required.
5. Refresh the data if necessary and explore the dashboard.

* Findings depend on the quality and completeness of the dataset.
* Observed relationships do not necessarily imply causation.
* The dashboard is intended for analytical and educational purposes and should not be treated as financial or investment advice.
